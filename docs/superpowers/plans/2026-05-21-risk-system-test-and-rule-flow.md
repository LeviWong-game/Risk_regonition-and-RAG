# 风险预测系统规则与实现流程说明

本文档只说明当前风险预测系统的规则逻辑和实现流程，不包含终端执行指令、调试命令或目录操作说明。

## 1. 系统目标

风险预测系统用于对基层矛盾纠纷文本进行规则化评估，输出风险等级、风险分数、风险原因和处置建议。

系统不是单纯的关键词分类器，而是把案件文本中的风险信号拆解为多个指标，再汇总成综合风险判断。这样做的目的有三个：

- 让每一次风险判断都有可解释依据。
- 让规则能够按场景持续调整。
- 让输出结果既能服务居民端解释，也能服务管理端复核。

## 2. 输入与输出

系统输入是一段案件文本，通常包含案件类型、案件标题和案情描述。

系统输出包括：

| 输出内容 | 说明 |
| --- | --- |
| 风险等级 | 分为 L1、L2、L3、L4 四级 |
| 风险分数 | 0 到 100 的综合分 |
| P 维度分 | 表示事件升级概率 |
| I 维度分 | 表示事件影响后果 |
| D 维度分 | 表示事件处置难度 |
| 触发规则 | 说明是否命中聚集、伤害、公共安全、司法介入等红旗信号 |
| 处置建议 | 根据风险等级给出对应处理方式 |
| 原因说明 | 展示主要风险指标和命中证据 |

## 3. 总体实现流程

系统整体按照以下顺序执行：

1. 读取案件文本。
2. 识别案件类型、标题和案情描述。
3. 对文本进行规范化处理，减少标点、空格、繁简表达、轻微错字带来的影响。
4. 根据关键词、别名和模糊匹配规则提取风险信号。
5. 对 12 个二级风险指标分别评分。
6. 根据案件类型进行弱先验修正。
7. 将 12 个二级指标聚合为 P、I、D 三个一级维度。
8. 使用综合公式计算基础风险分。
9. 命中红旗规则时抬高最低风险等级。
10. 对边界样本进行校准，减少轻微纠纷被高估或明显风险被低估。
11. 将最终分数映射为 L1 到 L4 风险等级。
12. 生成风险结论、处置建议和解释文本。

## 4. 风险等级规则

当前系统把风险等级划分为四档：

| 风险等级 | 分数区间 | 含义 | 建议处置 |
| --- | ---: | --- | --- |
| L1 | 0-26 | 低风险，影响范围小，升级可能性低 | 网格员或物业自行处置，保留回访 |
| L2 | 27-52 | 一般风险，存在持续投诉、协商困难或局部影响 | 调解员介入，组织协商并设置跟踪节点 |
| L3 | 53-80 | 较高风险，可能涉及多方、公共影响、明显损害或部门联动 | 街道或相关部门联合处置，提前做好稳控与预案 |
| L4 | 81-100 | 高风险，可能涉及暴力、公共安全、群体聚集、司法或公安介入 | 立即升级至公安、法院或应急体系联动处置 |

## 5. 指标体系

系统采用 P、I、D 三个一级维度。

P 表示升级概率，关注纠纷是否会继续恶化。它包含：

- 冲突强度
- 持续性或复发性
- 涉事主体复杂度
- 升级触发信号

I 表示影响后果，关注事件造成的实际影响。它包含：

- 影响范围
- 安全或健康损害
- 经济或民生损失
- 公共秩序或舆情影响

D 表示处置难度，关注基层调解和部门协调的复杂程度。它包含：

- 法律与事实争议度
- 跨部门协调难度
- 调解资源与时效压力
- 弱势群体或紧迫性

## 6. 单项指标评分规则

每个二级指标都按照 1 到 5 档评分。

评分不是简单地“命中一个词就定档”，而是结合三类信息：

1. 命中的最强风险词。
2. 命中风险词的数量。
3. 命中风险词分布在哪些强度层级。

如果只命中一个中等风险词，指标分会比较稳定；如果同时命中多个中高风险词，系统会在基础档位上增加小幅分值，使风险强度更接近真实案情。

## 7. 文本匹配规则

文本匹配层主要处理以下问题：

| 匹配能力 | 作用 |
| --- | --- |
| 字段识别 | 从文本中识别案件类型、标题和案情 |
| 关键词匹配 | 识别工伤、聚集、报警、欠薪、堵路、舆情等风险信号 |
| 别名匹配 | 处理同一风险信号的不同说法 |
| 模糊匹配 | 降低轻微错字、格式差异带来的漏判 |
| 否定判断 | 避免“没有报警”“未发生伤害”等表达被误判为风险命中 |
| 案件类型匹配 | 识别劳动争议、物业纠纷、环境污染、土地权属等案件类别 |

## 8. 案件类型先验规则

案件类型会影响风险判断，但不会直接决定最终等级。

系统采用弱先验融合方式：

- 如果案情文本证据很少，案件类型的参考作用更大。
- 如果案情文本证据很充分，系统主要相信文本本身。
- 如果案件类型与文本信号冲突，最终判断仍以文本证据为主。

例如，劳动争议通常会提高经济损失、弱势群体紧迫性和跨部门协调难度的初始判断；但如果文本中没有升级、伤害、欠薪等具体信号，系统不会仅凭“劳动争议”直接判为高风险。

## 9. 综合评分规则

系统先把 12 个二级指标转换到统一量纲，再按权重汇总为 P、I、D 三个维度。

综合分由四部分共同构成：

- P 与 I 的耦合项，用于表示“容易升级且影响较大”的复合风险。
- P 的单独贡献，用于体现升级概率。
- I 的单独贡献，用于体现实际影响。
- D 的单独贡献，用于体现处置难度。

这种混合计算方式比单纯相乘更稳健。它可以避免某些“影响很大但暂时未激烈冲突”的案件被压得过低，也能避免只因情绪强烈但影响有限的案件被过度拔高。

## 10. 红旗规则

红旗规则用于处理必须优先升级的场景。

如果命中以下风险信号，系统会提高最低风险等级：

| 红旗类型 | 示例场景 | 规则效果 |
| --- | --- | --- |
| 人身伤害或暴力风险 | 殴打、动手、砍伤、重伤、暴力威胁 | 至少进入较高风险 |
| 公共安全隐患 | 火灾、爆炸、燃气泄漏、中毒、重大隐患 | 至少进入较高风险 |
| 聚集或舆情扩散 | 聚集、围堵、堵路、拉横幅、媒体关注、网络传播 | 至少进入较高风险 |
| 司法或公安介入 | 公安介入、法院受理、立案、司法程序 | 进入高风险 |
| 多个红旗叠加 | 同时出现伤害、聚集、公共安全等信号 | 进入高风险 |

红旗规则的作用是防止综合分还没有完全拉高时，系统漏掉现实中必须升级处置的案件。

## 11. 边界校准规则

系统还设置了边界校准逻辑，用于处理容易误判的样本。

主要包括三类：

1. 低风险保护：对轻微邻里纠纷、楼上楼下矛盾、普通住户摩擦等场景，如果没有红旗信号，且各项指标都较低，则限制其被过度拔高。
2. L2 与 L3 边界降噪：如果案件分数接近较高风险区间，但没有聚集、伤害、公共安全、跨部门强介入等强信号，则避免轻易判为 L3。
3. 明确损害补偿：如果文本出现健康损害、排放超标、公共设施长期不可用、出行严重受阻等明显影响，即使基础分偏低，也会补足到较高风险。

## 12. 输出解释规则

系统输出解释时，会优先展示各维度中最突出的风险指标。

解释文本通常包含：

- P 维度中最主要的升级原因。
- I 维度中最主要的影响原因。
- D 维度中最主要的处置难点。
- 是否命中红旗规则。
- 对应风险等级的处置建议。

这样可以让使用者知道系统为什么给出当前等级，而不是只看到一个分数。

## 13. 当前测试结论

本轮验证集中共有 26 条样本。

| 指标 | 结果 |
| --- | ---: |
| 样本总数 | 26 |
| 预测正确 | 22 |
| 预测错误 | 4 |
| 准确率 | 0.8462 |
| 加权 F1 | 0.8381 |
| 分数区间命中率 | 0.8462 |
| 高估样本 | 4 |
| 低估样本 | 0 |

当前系统在 L2 和 L3 样本上的表现较稳定，但仍存在低风险样本被高估的问题。验证集中没有真实 L4 样本，因此高风险场景的召回能力还需要单独补充样本验证。

## 14. 后续优化方向

后续建议重点优化以下方向：

1. 补充 L4 高风险样本，覆盖暴力、公共安全、群体聚集、司法介入等场景。
2. 继续细化 L1 与 L2 边界，降低轻微纠纷被高估的概率。
3. 复核物业、环境污染、调解受阻等容易跨等级误判的场景。
4. 扩大验证集规模，降低小样本带来的指标波动。
5. 保持规则解释可读，确保每一次等级判断都能追溯到具体指标和证据。
